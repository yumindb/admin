使用說明書YU MIN ADMIN

裕民工務管理系統 — 使用說明書

每個功能的操作步驟都在這裡。上面的搜尋框隨時可以用；每一節都有「朗讀」按鈕，可以用聽的。

用聽的： 每個標題旁邊有「朗讀」按鈕，按一下，手機或電腦就會把那一段唸給你聽；再按一次就停。（用手機請把音量打開）
第 1 章

快速開始

打開系統

用手機或電腦的瀏覽器（Safari、Chrome 都可以）打開這個網址（點了就開）：

https://yumin-admin.vercel.app

不用安裝任何 App。建議照下面步驟把它放到手機主畫面，以後點圖示就開。

加到手機主畫面（做一次就好）

iPhone（Safari）：

  1. 打開網址後，按畫面下方中間的「分享」按鈕（一個往上的箭頭）。
  2. 往下滑，點「加入主畫面」。
  3. 按右上角「新增」。完成！主畫面會多一個「裕民工務」圖示。

Android（Chrome）：

  1. 打開網址後，按右上角三個點。
  2. 點「加到主畫面」（或「安裝應用程式」）→ 按「新增」。

登入

  1. 輸入帳號與密碼（辦公室會給你）。帳號是英文小寫，例如 supervisor。
  2. 按「登入」。登入後會直接進到你角色的首頁，之後幾天內不用重新登入。
注意：密碼連續打錯 3 次會暫時鎖 15 分鐘。忘記密碼不用慌 — 請辦公室幫你重設一組新的。

第一次登入請先改密碼

  1. 按右上角的人像（電腦版是你的名字）。
  2. 在「修改密碼」區：輸入目前密碼 → 輸入新密碼兩次 → 按確認。
小撇步：迷路的時候，按最上面的「裕民工務 管理系統」字樣就會回到首頁；按右上角的「？」隨時可以打開這本說明書。

第 3 章

現場的每一天（現場人員／工地主任都適用）

GPS 打卡

  1. 到工地後，打開系統，按底部的「打卡」。
  2. 第一次會問「允許使用位置嗎？」→ 按允許。只問這一次，之後不會再吵你。
  3. 系統會自動推薦離你最近的案件，確認沒錯 → 按大大的「上班打卡」。畫面會顯示你離工地幾公尺。
  4. 收工離開前，同一頁按「下班打卡」。
小撇步：人在公司或路上也可以打卡 — 案件選「無案件」，寫一句備註就好。
小撇步：站得離工地遠一點也打得進去，只是會標「超出範圍」的黃色字，方便日後對照，不影響打卡。
注意：山區訊號差送不出去？不用重打。系統會自動把這筆存在你手機裡排隊，等你回到有訊號的地方、再打開這個網頁，它會自己送出（畫面會顯示「待送 N 筆」）。

現場回報（拍照回報狀況）

看到任何值得記錄的事 — 材料到了、做到哪了、漏水裂縫、業主交代 — 拍照傳上來，主任和老闆馬上看得到。

  1. 按底部的「新增」（主任按「回報」再按「新增回報」）。
  2. 選案場。系統會把你最近去過的排在最前面。
  3. 按「拍照／加照片」拍或選照片（可以好幾張）。
  4. 寫一句話說明（例：「三樓管線排完八成」）→ 按「送出回報」。
回報的狀態意思
待整合已送出，等主任把它「併入」當天日誌。這期間你還可以編輯或刪除。
已併入日誌主任已把它收進日誌，照片也一起帶進去了。
已封存辦公室處理完收起來了。

我的案場

底部「案場」列出你最近打卡、回報過的工地，依最近接觸排序。每個案場旁邊就有「打卡」「新增回報」的捷徑按鈕，還有「地圖」可以導航。

第 4 章

工地主任 — 施工日誌

日誌的四種狀態

狀態意思你要做什麼
草稿還沒送出，只有你看得到繼續填完、送出
簽核中已送出，正在辦公室或老闆那關不用做事，等就好
已核定老闆簽完了，這份定案沒事了，可下載 PDF
已退回某一關覺得要修改看原因 → 修改 → 重送

填一份日誌（每天五分鐘）

  1. 底部「日誌」→ 按「新日誌」。
  2. 選案件。日期自動帶今天，天氣用按的（晴／多雲／陰／雨…上午下午各選一次）。
  3. 填本日出工人數。累計人次系統自動加總，不用心算。
  4. 勾今天做的工項：清單就是標單匯入的項目。項目太多就用上面的搜尋框打兩個字。做完 100% 的工項會自動從清單消失，不會重複勾。
  5. 每個勾起來的工項按 ＋ － 填數量。「一式」的工項會改成填百分比，例如今天做了 30% 就填 30。
  6. （有外包才填）外包工別與機具：按「＋ 新增工別」填人數。
  7. （有的話）勾選現場回報把它併入日誌 — 照片自動跟著進來；臨時追加的工作按「新增臨時項」記一筆（之後辦公室會處理報價）。
  8. 拍照：施工照片直接拍或從相簿選，每張可寫說明。
  9. 用手指簽名 → 按「送出」。送出後會依序給辦公室、老闆簽。你隨時可在「日誌」看它走到哪一關。
小撇步：填到一半被叫走？直接關掉沒關係 — 草稿每秒自動存在你的手機裡，回來打開同一頁會自動還原。
小撇步：簽名簽過一次後，下次可以直接用「上次的簽名」，不用每份重簽。

複製昨天的日誌

每天做的內容差不多時，不用重勾一遍：

  1. 「日誌」列表找到昨天那份，點進去。
  2. 按「複製為新日誌」。工項勾選、外包工別、天氣都幫你帶好，日期是今天；照片、備註、簽名不會帶（要重新拍、重新簽）。
  3. 改一下數量 → 拍今天的照片 → 簽名送出。

日誌被退回了怎麼辦

  1. 「日誌」列表找到紅色「已退回」那份，點進去。退回的原因寫在最上面（例：「請補拍箱內配線」）。
  2. 按「編輯」照原因修改（補照片、改數量…）。
  3. 重新簽名 → 送出。會重新走一次簽核。
注意：退回的日誌放著不管，老闆的儀表板會亮紅燈提醒「退回未重送」— 盡快處理。

幫別人簽核（待複核、假單）

現場人員送的假單第一關是你：上方「請假」有紅色數字時，點進去看內容 → 核准或退回。你自己請假則送給辦公室和老闆簽。

第 5 章

辦公室助理 — 案件與帳的管家

開新案件

  1. 「案件總覽」→ 按「開新案件」。
  2. 填案件名稱、承接公司、地點、業主、開工／預計完工日期。案號可以自己編（例 YM-2026-005），留空也可以。
  3. 設定工地位置（給 GPS 打卡用）：貼上 Google 地圖網址，或直接在小地圖上點工地位置。旁邊的「範圍」預設 200 公尺，大工地可以調大。
  4. 按「建立」。建好後畫面會提示下一步：匯入標單工項。

匯入標單（Excel 變工項）

  1. 進案件頁 → 按「匯入工項」。
  2. 選 Excel 標單檔（.xlsx）。系統會解析出分類、工項、數量，先給你「預覽」，沒有動到任何資料。
  3. 檢查預覽的樹狀清單：不要的列可以勾「略過」。
  4. 按「確認匯入」。一千多項的標單也是幾秒鐘完成。
小撇步：之後拿到追加版標單再匯一次就好 — 同名工項自動合併更新、新項目自動加入，你手動改過的不會被蓋掉。匯錯了也有「撤銷此次匯入」。
小撇步：沒有標單的小案子（例如住宅水電），在案件頁按「＋ 新增工項」手動建幾筆就能開始填日誌。

審核日誌

  1. 上方「待審核」（有紅色數字 = 有幾份等你）。
  2. 點開一份：先看摘要卡（工項數、照片數、出工人數），再往下對細項。系統會自動提醒「這個案子還有哪些工項好像漏填」。
  3. 沒問題 → 簽名 →「通過」；有問題 →「退回」並寫清楚原因。通過後自動送老闆核定；也可以勾很多份一起「批簽」。

追加的錢怎麼收回來：未簽約 → 報價 → 追加合約

工地臨時追加的工作，主任填日誌時就記了一筆「未簽約」。這些要在月底由你結算收尾，才不會漏收：

  1. 案件頁往下捲到「未簽約施工內容」區塊（或看報表「本月超工／未簽約」總表）。
  2. 每一筆按「編輯」補上單價（= 已報價）。
  3. 業主同意後：勾選幾筆 →「打包成追加合約」，填合約名稱與總價。從此變成正式的合約項目，進度、金額都會跟著算。
注意：老闆儀表板的「本月新增合約外金額」就是從這裡來的 — 未簽約放著不報價，錢就會漏掉。

結案

  1. 案件頁右上按「結案」。
  2. 系統會先自動盤點：還有幾筆未簽約沒報價？幾份日誌卡在簽核？有錢沒收完會整個變紅色警告。
  3. 都處理完（或確認可以放掉）→ 按確認。結案後主任就不能再對這案子填日誌、打卡；案件可以隨時「重新開啟」。

人員管理

上方「人員管理」：新增帳號（設帳號、姓名、角色、初始密碼）、重設密碼（有人忘記時）、停用（離職時 — 帳號停用後立刻不能登入，但他過去的紀錄都留著）。每個人的「最後登入」時間也在這頁。

補登打卡（有人忘記打卡時）

  1. 「報表」→「現場出勤（明細）」→ 按「補登打卡」。
  2. 選人員、案件、上／下班、日期時間，填補登原因（必填，例：手機沒電）。
  3. 按「確認補登」。補登的紀錄會標「補登」字樣，跟現場 GPS 打卡分得清清楚楚。

報表（上方「報表」）

報表什麼時候看
工項累計（跨案）對進度、請款前，可下載 Excel
本月超工／未簽約月底追加對帳用
案件進度總覽全部案子的進度％一頁看完
今日打卡儀表板早上看誰還沒打卡（紅綠燈）
現場出勤（明細）算薪資、查某人某天，可下載 Excel、可補登
簽核延遲分析看日誌卡在哪一關太久
登入紀錄誰在什麼時候、用什麼裝置登入過
操作紀錄誰改過單價、人員資料、合約（自動留底，不可竄改）
第 6 章

老闆 — 三十秒掌握全公司

儀表板（首頁）

打開就是紅綠燈：綠色不用管，黃色瞄一眼，紅色點進去。

卡片在講什麼
需要您出手真正卡住的事：退回超過 2 天沒重送的日誌、超過 5 天沒新日誌的案場
待核定幾份日誌等你簽，最久等了幾天
進度落後案場開工兩個月進度還不到三成的案子
到期案件已超過或 7 天內到預計完工日的案子
今日未打卡主任今天還沒打卡的主任名單
本月新增合約外金額這個月新冒出來的追加工作值多少錢

核定日誌

  1. 按「待核定」（紅色數字 = 幾份）。
  2. 點開：先看摘要卡與照片，有疑問往下看工項明細。
  3. OK → 手指簽名 →「核定」。簽完自動跳下一份，全部簽完會回列表。
  4. 有問題 →「退回」：可以點現成的原因（照片不夠清楚／工項數量怪…）或自己打字。主任會看到原因，修好重送。

批簽（一次簽很多份）

「待核定」列表上方可以「全選」或逐份勾選 → 按「批簽選取」→ 簽一次名，全部完成。快速篩選（無照片／無工項／卡很久）幫你先挑出可疑的單獨看。

我簽過的

上方「我簽過的」— 你歷來核定、退回過的每一份都查得到，含當時的簽名圖。

小撇步：手機底部有「回報」分頁 — 現場拍的照片（滲水、缺失）你隨時看得到，也可以自己拍照回報交辦。
第 7 章

大家都會用到的

請假

  1. 上方（或底部）「請假」→ 按「新請假」。
  2. 選假別（病假／事假／特休…）、起訖時間、寫事由 → 送出。
  3. 假單會自動一層層往上簽：現場人員 → 主任 → 辦公室 → 老闆；主任的假 → 辦公室 → 老闆。走到哪一關、准了沒，在「我的請假」隨時看得到；還沒簽完的可以自己取消。

輪到你簽別人的假時，「請假」字樣旁會出現紅色數字。

紅色小數字（徽章）是什麼

畫面上看到紅色小數字，意思都一樣：「有幾件事等你處理」。點進去做完，數字就消失。

下載 PDF 與 Excel

PDF：已核定的日誌可以下載正式的 PDF（含四關簽名圖），在日誌頁按「下載 PDF」；日誌列表也能多份一起下載。Excel：案件工項進度、月報、出勤、跨案工項都有「下載 Excel」按鈕，給請款、算薪資用。

案件大事記

每個案件頁往下捲有「案件大事記」：這個案子從建立、匯標單、每份日誌的簽核、追加合約、現場回報 — 誰在什麼時候做了什麼，一條時間軸看完。想確認某件事是哪天發生的，來這裡對照就好。

第 9 章

常見問題

要不要下載 App？
不用。它是網頁，Safari 或 Chrome 打開就能用。照第 1 章把它加到主畫面，用起來跟 App 一樣。
忘記密碼怎麼辦？
請辦公室助理（或老闆）到「人員管理」幫你重設一組，再用新密碼登入。自己記得密碼想換的話：右上角人像 → 修改密碼。
打卡會不會被追蹤行蹤？
不會。只有你「按下打卡那一刻」會記位置，其他時間系統完全不知道你在哪。
我在工地打卡卻顯示「超出範圍」？
工地座標可能標得不準，或 GPS 飄移。照常打卡沒關係（只是黃色標註），然後請辦公室在案件編輯頁把工地位置校正一下。
日誌送出後發現填錯了？
還在「簽核中」的話，請下一關（辦公室或老闆）把它退回，你就能修改重送。已「核定」的日誌原則上不再改 — 有重大錯誤請找辦公室處理，所有修改都會留紀錄。
照片會不會傳一傳不見？
不會。照片存在雲端，每天自動備份到第二個地方。上傳失敗時畫面會告訴你，按重試即可。
為什麼我看不到某些功能？
每個角色看到的功能不一樣（第 2 章功能地圖）。現場人員本來就沒有「審核」，主任本來就沒有「人員管理」— 不是壞掉。
兩個人可以同時用嗎？會不會互相蓋掉？
可以，各簽各的帳號互不影響。同一份日誌同時被兩個人簽核時，系統會擋下後簽的那位並提示已被處理。
手機換了新的，資料還在嗎？
在。所有送出過的資料都在雲端，新手機登入同帳號就全部看得到。只有「還沒送出的草稿」存在舊手機裡，換機前記得把草稿送出。
可以用電腦用嗎？
可以，同一個網址。辦公室的功能（匯標單、報表）用電腦比較順手；現場的功能（打卡、拍照）用手機比較順手。
LINE 會不會通知我？
還不會，LINE 通知是下一階段的計畫。目前請養成習慣：主任每天收工填日誌，辦公室和老闆看到紅色數字就點進去。

疑難排解

登入一直失敗
① 帳號是英文小寫，前後不要有空格。② 密碼分大小寫。③ 連錯 3 次會鎖 15 分鐘 — 等一下再試，或請辦公室重設密碼。
GPS 一直定位不到
① 確認手機的「定位服務」有開（iPhone：設定 → 隱私權 → 定位服務；Android：下拉快捷開關）。
② 確認有允許瀏覽器使用定位（iPhone：設定 → Safari → 位置；或網址列左邊的鎖頭 → 網站設定）。
③ 走到開闊處按「重新定位」。
④ 還是不行 → 照常工作，請辦公室補登打卡（見下一條）。
忘記打卡／手機沒電，怎麼補？
跟辦公室說一聲就好。辦公室在「報表 → 現場出勤」按「補登打卡」，選你的名字、案件、時間，填上原因（例：手機沒電）。補登的紀錄會標示「補登」。
送出時轉圈圈很久／失敗
多半是工地訊號差。打卡和回報會自動存進待送佇列，換個地方開網頁就自動補送；日誌草稿一直都在你手機裡，訊號好了再按一次送出即可。都不行時，先用手機拍好照片，回到訊號好的地方再補填。
照片上傳失敗
畫面會標出失敗的那幾張，按「重試」。連續失敗多半是訊號問題 — 照片還在你手機相簿裡，不會不見，稍後再補傳。
畫面出現「系統發生錯誤」和一串代碼
先按「重試」；不行就把錯誤代碼截圖傳給辦公室，由辦公室回報 Evelyn。你填的資料多數情況都還在。
頁面看起來怪怪的／按鈕跑版
下拉重新整理一次；還是怪就把瀏覽器完全關掉重開。長期沒更新的舊手機瀏覽器建議更新一下。
